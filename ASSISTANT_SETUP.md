# Настройка AI Ассистента для Movike

Этот документ описывает, как был настроен AI ассистент разработчика для проекта Movike.

## Что было сделано

### 1. Создана документация проекта

В репозитории созданы следующие файлы:

- **README.md** - основная информация о проекте Movike
- **project/docs/PROJECT_STRUCTURE.md** - детальное описание структуры проекта и модулей
- **project/docs/API_REFERENCE.md** - справка по API, классам и методам
- **project/docs/CODE_STYLE.md** - руководство по стилю кода + **правила безопасности**

### ⚠️ Правило безопасности: Удаление кода

В документацию добавлено важное правило:

**Любые запросы на удаление кода требуют подтверждения пользователя.**

Это защита от:
- Логических бомб (вредоносные команды на удаление)
- Случайного удаления важного кода
- Массового удаления без контроля

**Процесс:**
1. AI показывает, что будет удалено
2. Объясняет причину
3. Ждет подтверждения (да/нет)
4. Только после подтверждения удаляет код

См. подробности в `project/docs/CODE_STYLE.md` (раздел "Безопасность кода")

### 2. Создана RAG система для документации

**Файл:** `project/docs/simple_rag.py`

RAG (Retrieval-Augmented Generation) система индексирует документацию проекта.

**Что индексируется:**
- `README.md` - основная документация
- `project/docs/*.md` - вся техническая документация

**Статистика:**
- Всего файлов: 4
- Всего чанков: 46
- Размер чанка: 500 символов

**Использование:**
```bash
# Индексация
python3 project/docs/simple_rag.py index

# Поиск
python3 project/docs/simple_rag.py search "какие модули"

# Статистика
python3 project/docs/simple_rag.py stats
```

**Пример поиска:**
```bash
$ python3 project/docs/simple_rag.py search "структура проекта"
Найдено: 5 результатов
1. README.md (chunk 2, score: 3)
2. PROJECT_STRUCTURE.md (chunk 0, score: 2)
...
```

### 3. Настроен MCP сервер для работы с Git

**Файл:** `project/docs/mcp_git_server.py`

MCP (Model Context Protocol) сервер предоставляет информацию о текущей ветке git.

**Возможности:**
- `git_current_branch` - получение имени текущей ветки
- `git_branch_info` - детальная информация о ветке, статусе, коммитах

**Тестирование:**
```bash
cd /Users/admin/StudioProjects/Movike
python3 project/docs/mcp_git_server.py test
```

### 4. Создана команда /help

**Файл:** `.claude/commands/help.md`

Команда `/help` позволяет AI ассистенту отвечать на вопросы о проекте на основе документации.

**Примеры вопросов:**
- "Какая структура проекта Movike?"
- "Какие модули есть в проекте?"
- "Как добавить новый feature модуль?"
- "Какой стиль именования для классов?"
- "Как запустить сборку проекта?"

### 5. Настроены разрешения

**Файл:** `.claude/settings.local.json`

Настроены автоматические разрешения для безопасных команд:
- `./gradlew build`
- `./gradlew assembleDebug`
- `mkdir`, `chmod`
- `python3`, `pip install`

## Как использовать

### Команда /help

В Claude Code введите:
```
/help
```

Затем задайте вопрос о проекте, например:
```
Какие модули есть в проекте?
```

Ассистент прочитает соответствующую документацию и даст точный ответ.

### Информация о Git ветке

MCP сервер автоматически предоставляет информацию о текущей ветке. Вы можете спросить:
```
На какой ветке я сейчас работаю?
```

## Требования

### Для работы MCP сервера
- Python 3.7+
- Git установлен в системе
- Репозиторий является git репозиторием

### Для команды /help
- Claude Code CLI
- Доступ к файлам документации

## Обновление документации

Если вы вносите изменения в проект, обновите соответствующие файлы документации:

1. **Новый модуль** → обновите `PROJECT_STRUCTURE.md` и `README.md`
2. **Новый API** → обновите `API_REFERENCE.md`
3. **Изменения стиля** → обновите `CODE_STYLE.md`

Ассистент будет использовать актуальную информацию при ответах.

## Расширение функциональности

### Добавление новой команды

1. Создайте файл `.claude/commands/my-command.md`
2. Опишите поведение команды в формате промпта
3. Используйте `/my-command` в Claude Code

### Добавление MCP инструмента

1. Отредактируйте `project/docs/mcp_git_server.py`
2. Добавьте новый инструмент в `self.tools`
3. Реализуйте обработчик в `handle_request`
