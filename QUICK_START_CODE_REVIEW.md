# 🚀 Быстрый старт: AI Code Review

## Что это?

Автоматическая система ревью кода, которая анализирует Pull Requests и находит:
- Потенциальные баги
- Проблемы в коде
- Советы по улучшению
- Связанную документацию

## Как это работает?

1. **GitHub Actions** - автоматически запускается при создании/обновлении PR
2. **MCP Server** - получает diff и файлы из PR
3. **RAG System** - использует документацию для контекста
4. **Code Reviewer** - анализирует код и создает отчет

## 📦 Локальное тестирование

### 1. Создайте тестовую ветку

```bash
git checkout -b test-my-feature
# Внесите изменения в Kotlin файлы
git add .
git commit -m "feat: my new feature"
```

### 2. Запустите локальное ревью

```bash
# Из корня проекта
python3 assistant/code_reviewer.py sketch

# Или из папки assistant
cd assistant
python3 code_reviewer.py sketch
```

### 3. Посмотрите результат

```bash
cat assistant/review_output.md
```

## 🌐 Использование в GitHub

### 1. Создайте PR

```bash
git push origin test-my-feature
# Создайте PR через GitHub UI
```

### 2. Подождите результата

- GitHub Actions автоматически запустит ревью
- Результат появится в комментариях к PR
- Время выполнения: ~1-2 минуты

### 3. Посмотрите отчет

- Комментарий в PR будет содержать полный отчет
- Artifact с отчетом сохраняется на 30 дней

## 🔍 Что проверяется?

### Для Kotlin файлов:

#### ⚠️ Проблемы:
- `TODO/FIXME` комментарии
- `println()` в продакшн коде
- Force unwrap `!!`
- Пустые `catch` блоки

#### 🐛 Потенциальные баги:
- Утечки памяти (неочищенные listeners)
- `GlobalScope` вместо `lifecycleScope`
- Корутины без `Dispatcher`
- `Context` в `ViewModel`

#### 💡 Советы:
- `?.let {}` вместо `if != null`
- `when` вместо множественных `if-else`
- `const val` для констант

## 📊 Пример отчета

```markdown

**Base branch:** `main`
**Files changed:** 3

## 📄 `MainActivity.kt`

### ⚠️ Проблемы:

### 🐛 Потенциальные баги:
- Line 95: Listener не очищается в onDestroy

### 💡 Советы:
- Line 56: Используйте ?.let { } вместо if != null

## 📊 Сводка
- **Всего проблем:** 1
- **Потенциальных багов:** 1
- **Предложений:** 1
```
