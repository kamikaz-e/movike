# Movike Support FAQ

## Аутентификация и авторизация

### Почему не работает авторизация?

**Возможные причины:**

1. **Неверные учетные данные**
   - Проверьте правильность email и пароля
   - Убедитесь, что аккаунт активирован через email

2. **Проблемы с сетью**
   - Проверьте интернет-соединение
   - Убедитесь, что сервер доступен

3. **Истек токен доступа**
   - Попробуйте выйти и войти заново
   - Токены обновляются автоматически каждые 24 часа

4. **Технические проблемы**
   - Очистите кэш приложения
   - Переустановите приложение

### Как восстановить пароль?

1. На экране входа нажмите "Забыли пароль?"
2. Введите email, указанный при регистрации
3. Проверьте почту и перейдите по ссылке
4. Установите новый пароль

### Как изменить email аккаунта?

Перейдите в Настройки → Профиль → Изменить email. После изменения на новый email придет письмо с подтверждением.

## Работа с фильмами

### Почему не загружается список фильмов?

**Решения:**

1. **Проверьте интернет**
   - Откройте браузер и проверьте доступ к сайтам
   - Попробуйте переключиться с WiFi на мобильный интернет

2. **Обновите данные**
   - Потяните список вниз для обновления
   - Перезапустите приложение

3. **Проблемы с API**
   - API может быть временно недоступен
   - Попробуйте позже (обычно восстанавливается за 5-10 минут)

### Как добавить фильм в избранное?

1. Откройте страницу фильма
2. Нажмите на иконку сердца в правом верхнем углу
3. Фильм добавится в раздел "Избранное"

### Почему не работает поиск фильмов?

- Убедитесь, что введено минимум 3 символа
- Поиск регистронезависимый
- Попробуйте использовать другие ключевые слова
- Проверьте язык ввода (поддерживается русский и английский)

## Технические проблемы

### Приложение вылетает при запуске

**Шаги решения:**

1. Очистите кэш приложения:
   - Настройки Android → Приложения → Movike → Очистить кэш

2. Проверьте версию Android:
   - Минимальная поддерживаемая версия: Android 7.0 (API 24)

3. Обновите приложение до последней версии

4. Если проблема сохраняется:
   - Удалите и переустановите приложение
   - Сообщите нам номер версии и модель устройства

### Медленная загрузка изображений

- Проверьте скорость интернета
- Изображения кэшируются автоматически
- При медленном соединении используйте WiFi
- Можно отключить автозагрузку в настройках

### Не воспроизводится трейлер

Трейлеры загружаются с YouTube. Убедитесь, что:
- У вас установлено приложение YouTube
- YouTube не заблокирован в вашем регионе
- Есть стабильное интернет-соединение

## Подписка и платежи

### Какие есть тарифные планы?

1. **Бесплатный**
   - Базовый просмотр фильмов
   - Ограниченный поиск
   - Реклама

2. **Премиум** (299₽/месяц)
   - Без рекламы
   - Расширенный поиск
   - Раннее получение новинок
   - Скачивание для офлайн-просмотра

3. **Семейный** (499₽/месяц)
   - Все функции Премиум
   - До 5 пользователей
   - Семейные профили

### Как отменить подписку?

1. Google Play:
   - Откройте Google Play → Подписки → Movike → Отменить

2. Приложение:
   - Настройки → Подписка → Управление → Отменить

Подписка будет активна до конца оплаченного периода.

### Не прошел платеж

- Проверьте баланс карты
- Убедитесь, что карта не заблокирована
- Проверьте правильность реквизитов
- Попробуйте другой способ оплаты
- Свяжитесь с банком для проверки транзакции

## Настройки и персонализация

### Как изменить язык интерфейса?

Настройки → Язык → Выберите нужный язык. Приложение поддерживает русский и английский.

### Как настроить уведомления?

Настройки → Уведомления:
- Новинки кино
- Избранные фильмы
- Рекомендации
- Специальные предложения

### Как очистить историю просмотров?

Настройки → Конфиденциальность → Очистить историю. Это действие необратимо.

## Связь с поддержкой

### Как связаться с поддержкой?

**Email:** support@movike.app
**Время ответа:** 24-48 часов

**В приложении:**
Настройки → Помощь → Связаться с поддержкой

**При обращении укажите:**
- Описание проблемы
- Версию приложения
- Модель устройства
- Версию Android
- Скриншоты (если возможно)

### Часы работы техподдержки

- Понедельник - Пятница: 9:00 - 21:00 (МСК)
- Суббота - Воскресенье: 10:00 - 18:00 (МСК)
- Критичные проблемы обрабатываются 24/7

## Конфиденциальность и безопасность

### Как удалить аккаунт?

Настройки → Аккаунт → Удалить аккаунт.

**Внимание:**
- Все данные будут удалены навсегда
- Подписка будет отменена
- Восстановление невозможно

### Какие данные вы собираете?

Мы собираем:
- Email и основная информация профиля
- История просмотров (для рекомендаций)
- Технические данные (для улучшения приложения)

Мы НЕ собираем:
- Платежные данные (обрабатываются Google Play)
- Геолокацию
- Контакты
- Другие личные данные

Подробнее: Настройки → Политика конфиденциальности
