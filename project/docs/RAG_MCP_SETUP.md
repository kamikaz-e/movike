# Настройка RAG и MCP для проекта Movike

## Обзор

В проекте настроены две системы для улучшения работы AI ассистента:

1. **RAG (Retrieval-Augmented Generation)** - для поиска по документации
2. **MCP (Model Context Protocol)** - для получения информации о git репозитории

## 🎯 Что реализовано

### ✅ RAG система
- **Проиндексировано:** README.md + 3 файла из `project/docs/`
- **Всего чанков:** 46 фрагментов документации
- **Файлы:**
  - README.md (7 чанков)
  - PROJECT_STRUCTURE.md (7 чанков)
  - API_REFERENCE.md (13 чанков)
  - CODE_STYLE.md (19 чанков)

### ✅ MCP сервер
- **Текущая ветка:** получение через `git branch`
- **Информация о ветке:** статус, последний коммит, список веток
- **Открытые файлы:** попытка определить через workspace.xml и git status

### ✅ Команда /help
- Использует RAG для поиска в документации
- Использует MCP для информации о git
- НЕ читает файлы напрямую

## 🔍 Технические детали

### simple_rag.py

**Алгоритм:**
- Разбивка текста на чанки по 500 символов
- Поиск по ключевым словам (keyword matching)
- Подсчёт совпадений (TF-IDF упрощённый)
- Сортировка по релевантности

**Преимущества:**
- Нет внешних зависимостей
- Быстрая работа
- Достаточно для документации проекта

**Ограничения:**
- Нет семантического поиска
- Только точное совпадение слов
- Для продакшена нужны эмбеддинги

### mcp_git_server.py

**Возможности:**
- `git_current_branch` - текущая ветка
- `git_branch_info` - детальная информация
- `get_open_files` - попытка определить открытые файлы

**Реализация:**
- Использует `subprocess` для git команд
- Парсит workspace.xml для открытых файлов
- Fallback на `git status` если workspace.xml недоступен
