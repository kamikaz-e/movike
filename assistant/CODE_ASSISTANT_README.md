# 💻 Code Assistant - Консольный помощник для вопросов о коде

Рефакторированная версия Support Assistant, которая отвечает на вопросы о **коде проекта**, а не о пользовательских тикетах.

## 🚀 Быстрый старт

### Интерактивный режим (рекомендуется)

```bash
python3 assistant/code_assistant.py
```

### Один вопрос из командной строки

```bash
python3 assistant/code_assistant.py "Как использовать ApiService?"
python3 assistant/code_assistant.py "Где находится FeedViewModel?"
python3 assistant/code_assistant.py "Как работает авторизация?"
```

### Индексация документации

```bash
python3 assistant/code_assistant.py index
```

## 📋 Возможности

### 1. **Поиск в документации через RAG**
- Ищет в README.md и project/docs/*.md
- Использует семантический поиск
- Показывает релевантные фрагменты

### 2. **Поиск в коде**
- Ищет по всем Kotlin файлам (`.kt`)
- Показывает строки с совпадениями
- Исключает build директории

### 3. **Git контекст**
- Показывает текущую ветку
- Последний коммит
- Статус изменений

### 4. **Интерактивные команды**

В интерактивном режиме доступны команды:

- `index` - переиндексировать документацию
- `file:<путь>` - показать содержимое файла
- `code` - включить/выключить поиск в коде
- `exit` - выход

## 🔄 Отличия от Support Assistant

| Support Assistant | Code Assistant |
|-------------------|----------------|
| Отвечает на вопросы о пользователях/тикетах | Отвечает на вопросы о коде |
| Использует CRM данные (JSON) | Использует код проекта |
| Интеграция с тикетами поддержки | Интеграция с git контекстом |
| Flask REST API | Консольный интерфейс |

## 🛠 Технические детали

### Используемые компоненты

1. **RAG система** (`simple_rag.py`)
   - Индексация документации
   - Семантический поиск

2. **MCP Git Server** (`mcp_git_server.py`)
   - Информация о ветке
   - Статус git

3. **Поиск в коде**
   - Прямой поиск по файлам
   - Контекстные совпадения

## 📦 Установка и настройка

Никаких дополнительных зависимостей не требуется! Используются только стандартные библиотеки Python 3.

1. Убедитесь, что у вас есть индекс документации:
   ```bash
   python3 assistant/code_assistant.py index
   ```

2. Запустите помощника:
   ```bash
   python3 assistant/code_assistant.py
   ```

## 💡 Советы

1. **Используйте конкретные вопросы** - чем точнее вопрос, тем лучше ответ
2. **Проверяйте документацию** - сначала индексируйте документацию
3. **Используйте интерактивный режим** - удобнее для нескольких вопросов
4. **Просматривайте найденные файлы** - используйте команду `file:<путь>`

## 🐛 Устранение неполадок

### "Не найдено документов в RAG"

Выполните индексацию:
```bash
python3 assistant/code_assistant.py index
```

### "Низкая уверенность ответа"

- Проверьте наличие документации (README.md, project/docs/*.md)
- Попробуйте другие формулировки вопроса
- Включите поиск в коде (если выключен)
