# 📋 Примеры создания задач через чат

Вы можете создавать задачи прямо в чате, используя естественный язык. Ассистент автоматически распознает команду создания задачи и извлечет все необходимые детали.

## 🎯 Форматы команд

### Базовый формат
```
Create task: [Название задачи] with [приоритет] priority. Description: [Описание]
```

### Примеры на английском

**Пример 1: Простая задача с приоритетом**
```
Create task: Fix memory leak with high priority. Description: Images not released properly according to your documentation
```

**Пример 2: Задача с низким приоритетом**
```
Create task: Update documentation with low priority. Description: Add screenshots to UI component docs
```

**Пример 3: Критическая задача**
```
Create task: Fix security vulnerability with critical priority. Description: SQL injection in user authentication endpoint
```

**Пример 4: Средний приоритет (по умолчанию)**
```
Create task: Add dark mode support. Description: Implement dark theme across all screens
```

### Примеры на русском

**Пример 1:**
```
Создать задачу: Исправить утечку памяти с высоким приоритетом. Описание: Изображения не освобождаются из памяти правильно
```

**Пример 2:**
```
Добавить задачу: Обновить документацию. Описание: Добавить примеры использования API
```

## 📝 Что распознает ассистент

### Приоритеты
- **LOW** / **низкий** - для некритичных задач
- **MEDIUM** / **средний** - по умолчанию, если не указан
- **HIGH** / **высокий** - для важных задач
- **CRITICAL** / **критический** - для срочных задач

### Ключевые слова для создания задач
- `Create task:` / `Создать задачу:`
- `Add task:` / `Добавить задачу:`
- `New task:` / `Новая задача:`

### Структура команды
1. **Название задачи** - извлекается после "Create task:" до "Description:" или до конца, если нет описания
2. **Приоритет** - определяется по ключевым словам в тексте
3. **Описание** - извлекается после "Description:" или используется название, если описание не указано

## ✅ Примеры успешного создания

### Входной текст:
```
Create task: Fix memory leak with high priority. Description: Images not released properly according to your documentation
```

### Результат:
```
✅ Task created successfully!

ID: 1
Title: Fix memory leak
Description: Images not released properly according to your documentation
Priority: HIGH
Status: TODO
```

## 🔍 Как это работает

1. Вы отправляете сообщение в чат с командой создания задачи
2. Ассистент распознает intent "create_task"
3. Сервер парсит текст и извлекает:
   - Название задачи
   - Описание
   - Приоритет
4. Задача создается в базе данных
5. Вы получаете подтверждение с деталями созданной задачи

## 💡 Советы

1. **Всегда указывайте приоритет** - это поможет правильно организовать работу
2. **Используйте "Description:"** - для более точного извлечения описания
3. **Можно без описания** - если описание не указано, будет использовано название задачи
4. **Поддерживаются оба языка** - английский и русский

## 🚀 Быстрые команды

Вы также можете использовать метод `createTask()` в коде:

```kotlin
viewModel.createTask(
    title = "Fix memory leak",
    description = "Images not released properly",
    priority = "high"
)
```

Это автоматически сформирует правильную команду и отправит её в чат.

## 📱 Использование в приложении

1. Откройте чат с ассистентом
2. Введите команду создания задачи в любом из форматов выше
3. Нажмите отправить
4. Получите подтверждение с деталями созданной задачи

---

**Примечание:** Все созданные задачи сохраняются в памяти сервера. При перезапуске сервера задачи сохранятся, если используется флаг `--load-samples` или если задачи были сохранены в базе данных.
